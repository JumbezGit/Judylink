Judylink - cPanel deployment

1. In cPanel File Manager, open public_html.
2. Upload zanexcellent-cpanel-deploy.zip and extract it directly inside public_html.
3. In phpMyAdmin, select the zanexcel_db database and import backend/database/schema.sql.
4. Confirm backend/config.php contains the production database account assigned to zanexcel_db.
5. Set backend/uploads and its subdirectories writable (normally 755; use 775 only if required by the host).
6. Use PHP 8.1 or newer and enable PDO MySQL, cURL, mbstring, JSON, fileinfo, and GD.
7. Open https://zanexcellent.com/backend/api/health.php to verify database connectivity.
8. Open https://zanexcellent.com/backend/secure-operation-4f2a/ to sign in.

Security:
- The ZIP contains production database, administrator, and ScayPay sandbox credentials.
- Delete the ZIP from public_html immediately after extraction.
- Do not store the ZIP in a publicly downloadable directory after deployment.
- Change the administrator password and production secrets if this ZIP is shared.
